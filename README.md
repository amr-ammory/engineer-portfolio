# 🏗️ Engineer Portfolio — Amr Ammory

Professional portfolio website for **Amr Ammory**, a mechanical engineer specializing in advanced CAD design and precision manufacturing.

🌐 **Live Site:** [amr-ammory.github.io/engineer-portfolio](https://amr-ammory.github.io/engineer-portfolio/)

---

## ✨ Features

- **Bilingual** — Full Arabic & English support with instant language switching
- **Dark / Light mode** — Smooth theme toggle
- **Responsive design** — Optimized for mobile, tablet, and desktop
- **Smooth animations** — Powered by Framer Motion
- **16 engineering projects** — CAD designs, FEA analysis, and technical drawings
- **Downloadable CV** — Available in both Arabic and English

---

## 📂 Sections

| Section | Description |
|---|---|
| Hero | Introduction with CTA buttons |
| About | Personal background and stats |

| Blog | Engineering articles |

| Contact | Map, email, and social links |

---

## 🛠️ Tech Stack

- **Frontend:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS 4 + Radix UI
- **Animations:** Framer Motion
- **Forms:** React Hook Form + Zod
- **Backend:** Express.js (Node)
- **Deployment:** Vercel / GitHub Pages

---

## 🚀 Getting Started

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev

# Build for production
pnpm build
```
